# 🎙️ صوت نقي — تطبيق تسجيل الصوت وتنقيته من الضوضاء

تطبيق ويب (PWA) يعمل على الجوال والكمبيوتر: سجّل صوتك أو افتح ملفاً صوتياً، ثم نقّه من الضوضاء والطنين، واستمع للمقارنة بين النسختين، ثم حمّل النسخة النقية بصيغة WAV.

**كل المعالجة تتم داخل المتصفح على جهازك، ولا يُرفع أي صوت إلى الإنترنت.** ولا يحتاج التطبيق إلى أي مكتبات خارجية.

## المزايا

- تسجيل مباشر من الميكروفون مع مؤشر لمستوى الصوت وموجة حية
- فتح ملفات صوتية موجودة (WAV, MP3, M4A, OGG, WEBM)
- **إزالة الضوضاء الطيفية**: مرشح Wiener مع تقدير SNR مسبق (Decision-Directed)، وبصمة الضوضاء تُؤخذ تلقائياً من أهدأ المقاطع أو من أول ثانية في التسجيل
- إزالة الطنين الكهربائي (50/60 هرتز وتوافقياتها)
- فلتر تمرير عالٍ لإزالة الهمهمة واهتزازات الميكروفون
- بوابة ضوضاء ناعمة تكتم فترات الصمت دون أن تقطع نهايات الكلمات
- تحسين وضوح الصوت البشري (EQ)، وضاغط ديناميكي اختياري، ورفع المستوى تلقائياً
- مقارنة بصرية وسمعية بين الأصلي والمنقّى، مع إحصائيات نسبة الكلام إلى الضوضاء
- يعمل بدون إنترنت بعد أول فتح، ويمكن تثبيته كتطبيق على الشاشة الرئيسية

## التشغيل

التسجيل من الميكروفون يتطلب أن يُفتح التطبيق عبر `https` أو `localhost`:

```bash
npm start            # أو: python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

### النشر على GitHub Pages

من إعدادات المستودع: **Settings → Pages → Deploy from a branch**، ثم اختر الفرع والمجلد الجذري `/`.
بعدها يصبح التطبيق متاحاً عبر `https` ويمكن فتحه من الجوال وتثبيته.

## الاختبارات

```bash
npm test
```

تولّد الاختبارات إشارة شبيهة بالكلام وتضيف إليها ضوضاء بيضاء وطنيناً، ثم تتحقق من تحسن نسبة الإشارة إلى الضوضاء. النتيجة الحالية: SNR يتحسن من **8.4 dB إلى 19.8 dB**، والضوضاء في فترات الصمت تنخفض **25 dB**، ومستوى الكلام لا يتغير إلا بأقل من 1 dB.

## بنية المشروع

| الملف | الوظيفة |
|------|---------|
| `index.html` | الواجهة (عربية، من اليمين لليسار) |
| `style.css` | التصميم، ويدعم الوضع الليلي |
| `app.js` | التسجيل، والرسم، والتشغيل، والتحميل |
| `dsp.js` | محرك المعالجة: FFT، والفلاتر، وإزالة الضوضاء، والبوابة، والضاغط |
| `dsp-worker.js` | تشغيل المعالجة في خيط منفصل حتى لا تتجمد الواجهة |
| `sw.js`, `manifest.json` | العمل بدون إنترنت والتثبيت كتطبيق |
| `tests/` | اختبارات محرك المعالجة |

## تطويرات مقترحة

- إضافة نموذج ذكاء اصطناعي (مثل RNNoise أو DeepFilterNet عبر WebAssembly) لإزالة الضوضاء غير الثابتة كالأصوات المحيطة والموسيقى
- حفظ سجل التسجيلات في IndexedDB
- التصدير بصيغة MP3 أو M4A
