# 🎙️ صوت نقي — تطبيق تسجيل الصوت وتنقيته من الضوضاء

تطبيق ويب (PWA) يعمل على الجوال والكمبيوتر: سجّل صوتك أو افتح ملفاً صوتياً، ثم نقّه من الضوضاء والطنين، واستمع للمقارنة بين النسختين، ثم حمّل النسخة النقية بصيغة WAV.

**كل المعالجة تتم داخل المتصفح على جهازك، ولا يُرفع أي صوت إلى الإنترنت.** نموذج الذكاء الاصطناعي (RNNoise) مضمَّن في المشروع، وحجمه نحو 112 كيلوبايت، ولا يحتاج إلى خادم أو إلى اتصال بالإنترنت.

## المزايا

- تسجيل مباشر من الميكروفون مع مؤشر لمستوى الصوت وموجة حية
- فتح ملفات صوتية موجودة (WAV, MP3, M4A, OGG, WEBM)
- **إزالة الضوضاء بالذكاء الاصطناعي (RNNoise)**: شبكة عصبية تعزل الكلام حتى عن الضوضاء المتغيرة، مثل نقر الكيبورد وأصوات الشارع والضجيج المتقطع
- **ثلاث طرق قابلة للاختيار**: هجين (ذكاء اصطناعي ثم تنقية طيفية، وهو الافتراضي)، أو ذكاء اصطناعي فقط، أو طيفي كلاسيكي
- **إزالة الضوضاء الطيفية**: مرشح Wiener مع تقدير SNR مسبق (Decision-Directed)، وبصمة الضوضاء تُؤخذ تلقائياً من أهدأ المقاطع أو من أول ثانية في التسجيل
- إزالة الطنين الكهربائي (50/60 هرتز وتوافقياتها)
- فلتر تمرير عالٍ لإزالة الهمهمة واهتزازات الميكروفون
- بوابة ضوضاء ناعمة تكتم فترات الصمت دون أن تقطع نهايات الكلمات
- تحسين وضوح الصوت البشري (EQ)، وضاغط ديناميكي اختياري، ورفع المستوى تلقائياً
- مقارنة بصرية وسمعية بين الأصلي والمنقّى، مع إحصائيات نسبة الكلام إلى الضوضاء
- يعمل بدون إنترنت بعد أول فتح، ويمكن تثبيته كتطبيق على الشاشة الرئيسية

## التشغيل

التسجيل من الميكروفون يتطلب أن يُفتح التطبيق عبر `https` أو `localhost`:

```bash
npm start            # أو: python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

### النشر على GitHub Pages

من إعدادات المستودع: **Settings → Pages → Deploy from a branch**، ثم اختر الفرع والمجلد الجذري `/`.
بعدها يصبح التطبيق متاحاً عبر `https` ويمكن فتحه من الجوال وتثبيته.

## مقارنة الطرق

اختبار على تسجيل كلام حقيقي مدته 30 ثانية بمعدل 48kHz، مضافاً إليه ضوضاء تجعل نسبة الكلام إلى الضوضاء 5 dB. المقياس هو SI-SNR بالديسيبل (كلما كان أعلى كان أفضل):

| نوع الضوضاء | طيفي | ذكاء اصطناعي | هجين |
|---|---|---|---|
| بيضاء (هسهسة) | **15.0** | 11.1 | 11.5 |
| وردية | 10.1 | 11.9 | **12.4** |
| مروحة + طنين | 10.3 | 12.1 | **12.3** |
| نقر كيبورد + ضجيج متقطع | 5.0 (لا تحسّن) | 10.7 | **10.7** |

الخلاصة: الذكاء الاصطناعي ضروري للضوضاء المتغيرة. أما مع الهسهسة الثابتة الخفيفة فقد تعطي الطريقة الطيفية صوتاً أنقى وأكثر طبيعية، لذلك يبقى الاختيار بين الطرق متاحاً في الواجهة.

## الاختبارات

```bash
npm test
```

تشمل الاختبارات: دقة إعادة التشكيل، وتعويض تأخير RNNoise، وتفوّق الذكاء الاصطناعي على الطريقة الطيفية مع الضوضاء المتغيرة، والرجوع التلقائي إلى الطريقة الطيفية إذا تعذّر تحميل النموذج.

تولّد الاختبارات أيضاً إشارة شبيهة بالكلام وتضيف إليها ضوضاء بيضاء وطنيناً، ثم تتحقق من تحسن نسبة الإشارة إلى الضوضاء. النتيجة الحالية: SNR يتحسن من **8.4 dB إلى 19.8 dB**، والضوضاء في فترات الصمت تنخفض **25 dB**، ومستوى الكلام لا يتغير إلا بأقل من 1 dB.

## بنية المشروع

| الملف | الوظيفة |
|------|---------|
| `index.html` | الواجهة (عربية، من اليمين لليسار) |
| `style.css` | التصميم، ويدعم الوضع الليلي |
| `app.js` | التسجيل، والرسم، والتشغيل، والتحميل |
| `dsp.js` | محرك المعالجة: FFT، والفلاتر، وإعادة التشكيل، وRNNoise، والإزالة الطيفية، والبوابة، والضاغط |
| `dsp-worker.js` | يحمّل نموذج RNNoise ويشغّل المعالجة في خيط منفصل حتى لا تتجمد الواجهة |
| `vendor/rnnoise/` | نموذج RNNoise بصيغة WebAssembly مع رخصه |
| `sw.js`, `manifest.json` | العمل بدون إنترنت والتثبيت كتطبيق |
| `tests/` | اختبارات محرك المعالجة |

## تطويرات مقترحة

- نموذج أكبر وأدق مثل DeepFilterNet، للضوضاء الصعبة كالموسيقى وأصوات الأشخاص الآخرين
- حفظ سجل التسجيلات في IndexedDB
- التصدير بصيغة MP3 أو M4A
